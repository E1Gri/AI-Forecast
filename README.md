## Запуск проекта

### 1. Запуск Jupyter Notebook

Запустите Jupyter Notebook для работы с данными и ML-моделями:

```bash
jupyter lab
```

### 2. Запуск сайта и обновления прогноза

Из корневой директории проекта выполните:

```bash
docker run --rm --init \
  --name ai-forecast \
  -p 25565:8000 \
  ai-forecast
```

После запуска веб-интерфейс будет доступен по адресу:

```text
http://localhost:25565/
```

При запуске на удалённом сервере используйте его IP-адрес:

```text
http://IP_СЕРВЕРА:25565/
```

Скрипт `page_updater.py` отвечает за обновление прогноза, а `http.server` — за раздачу файлов веб-интерфейса из директории `front`.
